## Audit Module 

This module performs financial analysis and anomaly detection for properties.

### Features

- Calculate rental yield
- Detect anomalies:
  - Low Yield
  - Underpriced
  - Missing History
- Prevent duplicate anomaly insertion

### Evaluation

- Audit values are positive
- Low yield anomalies are correctly detected
- No duplicate anomalies exist

### Validation

Includes evaluation tests to ensure:
- Correct anomaly detection
- No duplicate anomalies
